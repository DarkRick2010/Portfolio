# Erick Boteleiro — Automações em Python

Automatizo tarefas repetitivas de pequenas e médias empresas: planilhas e relatórios, coleta de dados na web e atendimento automático por mensagens.

| Projeto | O que faz | Tecnologias |
|---|---|---|
| [📊 Consolidador de Planilhas](consolidador-vendas/) | Junta planilhas de várias lojas (com formatos diferentes) em um relatório Excel com resumos e gráfico | pandas, openpyxl |
| [🤖 Robô de Coleta de Preços](robo-coleta-precos/) | Percorre um catálogo online e exporta todos os produtos para Excel/CSV | requests, BeautifulSoup |
| [💈 Bot de Agendamento](bot-agendamento-telegram/) | Clientes agendam e cancelam horários pelo Telegram; o dono recebe avisos | API do Telegram |

Cada pasta tem um README explicando o problema, a solução e como rodar.
